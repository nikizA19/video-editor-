# 🎬 AI Видео Студио

Качваш суровите си клипове, пишеш с думи какво искаш, и студиото само прави монтажа:

- ✂️ **маха паузите** и мълчанието (jump cuts)
- 🔁 **маха сбърканите дубли** (ако кажеш изречение два пъти, остава само последното)
- 🔍 **zoom in / zoom out**: редува кадрите с приближаване, бавен zoom на важните моменти
- 🎞️ **преходи** (fade, плъзгане, бяла светкавица) при смяна на темата
- 🔊 **звукови ефекти**: whoosh, pop, ding, boom, вградени, не трябва да сваляш нищо
- 💬 **надписи** дума по дума, текущата дума светва в жълто (като в TikTok/Reels)
- 🏷️ **текст графики**: големи заглавия, които „изскачат“ на екрана
- 🎨 **цветове**: по-наситени, топли, студени или „кино“
- 🎵 **фонова музика**, която сама се снишава, когато говориш
- 📱 **формат** 9:16 за TikTok/Reels/Shorts, 16:9 за YouTube или 1:1

Всичко работи **на твоя компютър, безплатно** (ffmpeg + Whisper за разпознаване на реч).
По желание можеш да включиш Claude да „мисли“ монтажа вместо правилата (виж най-долу).

---

## Как да го пуснеш (еднократно)

**1. Инсталирай Python** (ако го нямаш): https://www.python.org/downloads/
На Windows при инсталацията **сложи отметка на „Add python.exe to PATH“**.

**2. Инсталирай ffmpeg** (програмата, която реално реже видеото):
- **Windows:** отвори PowerShell и напиши `winget install Gyan.FFmpeg`
- **Mac:** `brew install ffmpeg` (ако нямаш brew: https://brew.sh)

**3. Свали проекта:** зелен бутон **Code → Download ZIP** в GitHub и го разархивирай.

**4. Пусни студиото:**
- **Windows:** двоен клик на `start.bat`
- **Mac:** в Terminal: `cd` до папката и `./start.sh`

Първия път инсталира нужното (1-2 минути) и при първия монтаж сваля модела за реч (~500 MB).
После браузърът се отваря сам на **http://localhost:8000**.

### Обновяване

Не трябва да правиш нищо. **При всяко пускане `start.bat` / `start.sh` проверява за нова версия и я сваля сам.**
Нищо не губиш: проектите ти (папка `workspace/`), ключът (`.env`) и твоите звукови ефекти не се пипат.

## Как да го ползваш

1. **Качи клиповете** в „Твоите клипове“ (в реда, в който да вървят).
2. По желание качи **пример за стил** (видео или снимка, което ти харесва) и **музика**.
3. **Напиши какво искаш** или цъкни готовите бутони. Например:
   > Махни паузите и грешните дубли, надписи с главни букви, повече zoom, кино цветове. Заглавие: 3 ТРИКА ЗА МОНТАЖ
4. Избери **формат** (например 9:16 за TikTok) и натисни **Монтирай ▶**.
5. Гледай резултата. Не ти харесва нещо? Напиши поправката („по-малко zoom“, „без звукови ефекти“),
   остави отметката **„Поправи последния монтаж“** и монтирай пак.

### Думи, които студиото разбира (и на латиница, и на кирилица)

| Искаш | Пиши |
|---|---|
| Без zoom / повече zoom | `bez zoom` · `mnogo zoom` / `повече zoom` |
| Без звукови ефекти | `bez zvukovi efekti` / `без ефекти` |
| Без преходи | `bez prehodi` / `без преходи` |
| Без надписи | `bez nadpisi` / `без надписи` |
| Надписи с главни букви | `glavni bukvi` / `главни букви` |
| Бързо, динамично темпо | `agresivno`, `dinamichno`, `бързо` |
| Да не реже паузите | `ne mahai pauzite` |
| Вертикално видео | `tiktok`, `reels`, `shorts`, `9:16` |
| Цветове | `topli`, `studeni`, `kino`, `bez cvetove` |
| Заглавие на екрана | `zaglavie: ТЕКСТ` / `title: ТЕКСТ` |

### Съвети за най-бърз и добър резултат

- **Снимай на дубли.** Кажи изречение, пауза 1 секунда, следващото. Паузите са местата, където студиото реже.
- **Сбъркаш ли, просто кажи изречението отначало.** Повтореният дубъл се маха сам.
- **Снимай с добър звук** (микрофон или близо до телефона). Чистият звук = по-точни надписи и разрязване.
- **Лицето в горната половина на кадъра.** Zoom-ът приближава малко над центъра.
- **Първо монтирай, после поправяй.** По-бързо е от това да опишеш всичко перфектно от първия път.
- **Твои звукови ефекти:** сложи `whoosh.wav`, `pop.wav`, `ding.wav`, `boom.wav` или `click.wav`
  в папка `studio/assets/sfx/` и те ще се ползват вместо вградените.

## По желание: Claude да прави монтажа

Без нищо допълнително студиото работи в **Авто режим**: следва правила (редува zoom, whoosh при дълга пауза, маха повторени изречения).

Ако искаш **Claude да чете какво казваш** и да решава кое да махне, къде да има zoom, звук и графики,
и да гледа примерите ти за стил:

1. Направи API ключ на https://console.anthropic.com (плаща се на употреба, обикновено
   около няколко цента до десетина цента на монтаж за кратко видео).
2. В папката на проекта създай файл `.env` с ред: `ANTHROPIC_API_KEY=твоят-ключ`
3. Пусни студиото пак. Горе ще пише „Claude е включен“.

Ако нещо с Claude не стане, студиото само минава на Авто режим.

## За разработчици

```
studio/
  server.py     уеб сървър (FastAPI) + API
  pipeline.py   целият процес: анализ → план → рендер
  analysis.py   паузи (silencedetect), реч (faster-whisper), повторени дубли, анализ на примери
  planner.py    EditPlan: авто правила или Claude (structured output)
  render.py     ffmpeg: кадри, zoom, xfade преходи, ASS надписи, SFX, музика, loudnorm
  static/index.html   интерфейсът
tests/          end-to-end тест със синтетично видео (трябва само ffmpeg)
```

Тестове: `pip install pytest && python -m pytest -q`
Настройки чрез env: `PORT`, `STUDIO_WORKSPACE`, `CLAUDE_MODEL` (по подразбиране `claude-opus-5-5`).
